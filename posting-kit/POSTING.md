# Tie The Knot — TikTok posting kit

Human upload only. This repo is read-only toward TikTok: do not post, like, follow, or comment from Chrome, scripts, or MCP.

Slides are the latest no-CTA, beat-matched **1080×1920** PNGs on [`previews/`](https://github.com/darylbleach/tiktokslides/tree/daryl/ttk-unsplash-brand-slides-e228/previews) (`daryl/ttk-unsplash-brand-slides-e228`). They are **not** copied here.

## Exact upload steps (each carousel)

1. Save the PNGs to your phone (open the GitHub links below on the phone, or AirDrop / Files from this repo’s `previews/` folder).
2. Open the **TikTok** app.
3. Tap **+**, then **Photo** (not Video).
4. Add the PNGs **in the order listed** (01, then 02, then 03…).
5. Paste the caption for that carousel.
6. **Post**.

Repeat for all three carousels. Add a sound in TikTok if you want; the frames are already beat-matched.
